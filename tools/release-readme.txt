JUMPER CHICKEN @VERSION@
=======================

Jump from wall to wall, dodge the spikes, collect coins and unlock new
chickens, backgrounds and music. It gets faster the further you get!

START
  Windows: double-click JumperChicken.exe
  Linux:   double-click JumperChicken (or run ./JumperChicken in a terminal)

CONTROLS
  X / Space / mouse click   jump
  Arrow keys + X            menus and shop
  Backspace                 back
  M                         music on/off
  Esc                       quit

Your progress is saved in data/save.txt next to the game. Keep that file
when you update the game to keep your coins and unlocks.
